# Omnir Product Help Wiki Seed

This folder is the seed content for the public GitHub Wiki:

`https://github.com/SEI-Mkittok/omnir-refactor/wiki`

The application does not read these files directly. Product help sync reads the GitHub Wiki raw content using `omnir-product-help-manifest.json`.

Use this folder to review and stage changes, then copy the files into the wiki Git repository and push them there.
