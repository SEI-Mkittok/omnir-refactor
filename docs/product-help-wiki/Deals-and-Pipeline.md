# Deals and Pipeline

Deals track active revenue opportunities. The pipeline is the shared view of those opportunities by stage.

## Deal Basics

A useful deal usually has:

- Title
- Account
- Primary contact
- Owner
- Stage
- Value
- Expected close date
- Next activity

If any of these are unknown, note why.

## Pipeline Stages

Stages should represent meaningful progress, not optimism. Move a deal forward only when the customer's situation has changed.

Good stage movement is based on evidence:

- A meeting happened.
- A decision maker was identified.
- Requirements were confirmed.
- A quote was sent.
- Procurement began.

## Daily Deal Hygiene

Before a sales meeting, review:

- Deals without next activity.
- Deals past expected close date.
- Deals with stale stage movement.
- High-value deals without recent notes.

## Closing Discipline

Closed won should mean the opportunity is actually won. Closed lost should include enough context to learn from it.

Capture:

- Reason won or lost.
- Competitor if relevant.
- Timing notes.
- Follow-up opportunity if one exists.

## Manager View

Pipeline dashboards are only as strong as stage discipline. Managers should coach on record quality before interpreting forecast numbers.
