# Billing and Plans

Billing settings help admins understand plan status, usage, and invoices.

## Subscription

The subscription view shows the current plan and status.

Plan status may affect:

- Available features.
- Usage limits.
- Billing period.
- Upgrade or cancellation options.

## Usage

Review usage before inviting many new users or importing a large data set.

Common usage signals include:

- User count.
- Contact count.
- Plan tier.
- Feature availability.

## Invoices

Invoices provide billing history. If invoice data looks stale, wait briefly and refresh. Some billing updates depend on external provider webhooks.

## Plan Changes

Before changing plans:

- Confirm expected user and data volume.
- Review feature requirements.
- Check billing owner.
- Communicate the change internally.

## Questions

If billing information looks incorrect, contact your Omnir administrator or support owner with the workspace name, current plan, and what appears wrong.
