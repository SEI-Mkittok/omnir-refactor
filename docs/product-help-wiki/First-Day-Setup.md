# First Day Setup

The fastest way to get useful value from Omnir is to configure the workspace before inviting everyone.

## For Admins

Start in Settings.

1. Open Company Profile and confirm organization identity.
2. Open Users and invite the first internal users.
3. Review Roles, Profiles, Groups, and Sharing Rules.
4. Configure Document Numbering for quotes, tickets, invoices, and KB articles.
5. Configure Portal settings if customers will submit tickets.
6. Configure Integrations for email, calendar, and external tools.
7. Review Billing before adding a large user set.

Do not over-customize on day one. Start with the default structure, then add fields and layouts only where a real process needs them.

## For Sales Users

Begin with the customer records you already know:

1. Create or import accounts.
2. Add contacts to those accounts.
3. Create leads for unqualified interest.
4. Convert qualified leads into contacts, accounts, and deals.
5. Keep each deal's stage and next activity current.

Your goal is not data entry. Your goal is a pipeline that the team can trust.

## For Support Users

Start with ticket flow:

1. Create a test ticket.
2. Assign it to an owner.
3. Change status as work progresses.
4. Add internal notes and customer-facing comments where appropriate.
5. Review SLA behavior if policies are enabled.
6. Confirm customer portal access before sharing it externally.

## For Managers

Avoid judging dashboards until the team is using records consistently. First check:

- Are records assigned?
- Are statuses and stages current?
- Are close dates and due dates realistic?
- Are notes and activities being recorded?

Once those habits exist, dashboards become useful instead of decorative.
