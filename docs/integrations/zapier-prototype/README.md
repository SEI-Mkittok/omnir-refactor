# Zapier Prototype

This folder contains an early standalone Zapier Platform app prototype for Omnir/PraestOS.

It is preserved as integration reference material only. It is not wired into the main app runtime, CI, deployment, or package workspace. The product-facing integrations surface currently lists Zapier as `coming_soon`, and real automation should use the supported REST API plus outbound webhooks until this prototype is refreshed and formally connected.
